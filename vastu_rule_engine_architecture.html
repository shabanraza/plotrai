Layer 2 — rule engine (the core knowledge base)

The 8-direction grid — room placement rules (widely agreed across schools)

North (N)

Living room, study, water tank. Element: water. Deity: Kubera (wealth).

NE — Ishaan

Puja/prayer room. Must be lightest, open. No toilet, no kitchen ever.

East (E)

Main entrance preferred. Living room, guest bed. Morning sun = auspicious.

SE — Agni

Kitchen (fire element). Mandatory. Dining room also acceptable.

South (S)

Bedroom OK. No main entrance. Heavy walls here. No water.

SW — Nairitya

Master bedroom. Owner's room. Heaviest part of house. No entrance, no toilet.

West (W)

Children's room, dining, bathroom acceptable. Storage.

NW — Vayu

Guest bedroom, bathroom, garage. Air element = movement, guests leave.

Centre — Brahmasthan

Must stay empty/open. No toilet, no column, no heavy load. Sacred zone.

Hard constraint rules — must never be violated (score = 0 for room if broken)

H1
Toilet in NE → critical violation. Blocks wealth + spiritual zone.if room.type == "toilet" AND zone == "NE" → score=0, flag=CRITICAL
H2
Kitchen in SW → critical. Fire element clashes with earth/stability.if room.type == "kitchen" AND zone == "SW" → score=0, flag=CRITICAL
H3
Main entrance facing S of SE → high violation.if entrance.direction == "S" OR "SSE" → score=20, flag=HIGH
H4
Column or load-bearing wall in Brahmasthan center → critical.if center_zone.has_load → score=0, flag=CRITICAL
S1
Master bedroom NOT in SW → soft violation, suggest correction.if master_bed.zone != "SW" → deduct 15pts, flag=SOFT
S2
Staircase in NE → avoid. Use S, W, SW instead.if staircase.zone == "NE" → deduct 20pts, flag=HIGH

Layer 3 — layout generator algorithm

1
Divide plot into 9-zone Vastu Purusha Mandala grid based on actual dimensions. Each zone gets exact sq ft.
2
For each room in input list, find ideal zone from rule DB. Sort by constraint weight (hard first).
3
Try placement using bin-packing. If room fits ideally → place. If not → try adjacent zones by priority order.
4
If conflict (two rooms need same zone), resolve by: swap lower-priority room to next-best zone.
5
Place doors: main door in best pada (division) of preferred direction. Check 32-pada table.
6
Run constraint checker: score every placed room. Flag violations.
7
If score < threshold (e.g. 65), try alternate layout permutations (up to N iterations).
8
Return best-scoring layout. Generate SVG floor plan with zone overlay.

Layer 5 — remedy engine output structure

Free fixes

Furniture repositioning, color changes, plant placement, mirror removal

Low cost (₹500–5K)

Door shift, window addition, zone demarcation, color repaint

Structural (₹5K+)

Room function swap, wall removal, staircase relocation

Each remedy includes: violation description → why it matters → fix instruction → cost estimate → score improvement if applied
